' Design Practices applied:
' 1. Simplicity: Model broken into clear, focused classes (e.g., Course vs. CourseOffering, Notification vs. NotificationService).
' 2. Naming: Singular nouns, PascalCase for classes/enums, camelCase for attributes/methods.
' 3. Naming: Class names are short and descriptive.
' 4. Naming: Consistent PascalCase for classes.
' 5. Attributes: Carefully assigned to appropriate classes, avoiding bloated or sparse classes.
' 6. Operations: Classes have meaningful operations; no classes with only one or two trivial operations without justification.
' 7. Operations: Notification class, initially a data holder, now includes 'markAsRead()' to encapsulate behavior.
' 8. Responsibilities: Classes like CourseOffering, Student, Instructor have manageable sets of responsibilities.
' 9. Access Methods: Core behaviors are shown; implicit getters/setters assumed for attributes as per standard practice.
' 10. Operation Categories: Operations have appropriate visibility (+ public).
' 11. Relationships: Reduced complexity, clear, and purposeful relationships.
' 12. Unidirectional: Relationships are generally unidirectional where logical (e.g., NotificationService creates Notification).
' 13. Inheritance: Single-level inheritance used (User, Course hierarchies).
' 15. Multiplicity: Clearly defined for all associations.
' 16. Relationship/Role Names: Used to clarify the purpose of associations.
' 17. Role Names: Noun phrases.
' 18. Relationship Names: Verb phrases.
' 20. Association Class: EnrollmentRecord used as an association class for complex relationship attributes.
' 21. Relationships: Identified and typed appropriately.
' 23. Naming: Descriptive and meaningful names for all elements.
' 24. Consistency: Uniform style, naming conventions, and layout.
' 25. Notes: Explanatory notes provided for clarity and design rationale.
' 26. Redundancy: Avoided, e.g., NotificationService doesn't hold Notification message details.
' 27. Loose Coupling: Classes interact through well-defined interfaces, promoting modularity.
