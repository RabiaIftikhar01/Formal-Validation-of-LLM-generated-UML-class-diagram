Here is the design-level UML Class Diagram in PlantUML format, incorporating the provided user stories, use case diagram, domain model, and adhering to good design practices for extensibility and maintainability.

The design focuses on:
*   **Clear Responsibilities:** Each class has a well-defined purpose.
*   **Loose Coupling:** Classes interact through well-defined interfaces (methods) and managed relationships.
*   **Simplicity:** Avoids over-engineering by using attributes for categories instead of deep inheritance hierarchies when behavior doesn't significantly differ.
*   **Appropriate Relationships:** Uses generalization, aggregation, and association classes effectively, with determined multiplicities and roles.
*   **Access Control:** Uses public and private access modifiers for attributes and operations.
*   **Readability:** Consistent naming conventions and layout.
